## The design the tests must assume

The implementer follows it exactly:
- `apps/web/src/api/client.ts` gains `apiPost(path, schema)`, for a call with no body. It returns the parsed body on success. On a `4xx` whose body parses as `ErrorBody`, it returns a rejection the caller can read, rather than throwing. It throws on a network error, a `5xx`, or a body that fails validation.
- `apps/web/src/features/review/ReviewPanel.tsx`, exports `ReviewPanel({ documentId })`: everything about requesting and following a review on one document's page. It reads `GET /documents/:id`, and `GET /quota` for the `timeZone` used to format the reset date and "started at" time.
- Polling: while `current` is not null, it refetches `/documents/:id` every 1500 ms, using TanStack Query's conditional `refetchInterval`. When `current` becomes null it stops.

- `apps/web/src/app/documents/[id]/page.tsx` composes the feature. Findings content comes at the next stage, so here "Previous review" shows its label line and counts. Do not assert anything about finding content except its absence during a run.
