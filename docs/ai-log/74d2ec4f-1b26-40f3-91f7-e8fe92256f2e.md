|---|---|
| `next dev` | Start Next.js in development mode |
| `-H 127.0.0.1` | Which address to listen on (`H` from hostname). `127.0.0.1` is the computer itself, nothing from outside can connect here |
| `-p 3000` | Which port (`p` from port), so the address in the browser is `localhost:3000` |

- **Now:** the page opens only on the computer itself.

For you nothing changes: `localhost:3000` works as before. If you want to open the app from a phone, `-H 127.0.0.1` will have to be removed.
